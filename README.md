# WhatsApp Flight Bot

בוט WhatsApp Web למעקב אחר טיסות מנתב״ג. החיבור משתמש ב־QR וב־session מקומי שנשמר בתיקיית `.wwebjs_auth`.

## הפעלה

```bash
./runwhatsapp.sh
```

בהפעלה הראשונה הסקריפט מתקין את חבילות Node, יוצר סביבת Python מקומית ומתקין את התלויות מ־`requirements.txt`. נדרשים Node.js ו־Python 3; אם מגדירים `PYTHON_EXECUTABLE`, הסקריפט ישתמש בו במקום בסביבת ברירת המחדל.

### Termux / Android

ב־Termux יש להתקין את דרישות המערכת פעם אחת לפני ההפעלה:

```bash
pkg update
pkg install nodejs python chromium
```

הסקריפט מדלג בכוונה על הורדת Chromium של Puppeteer, שאינה נתמכת ב־Termux, ומשתמש ב־Chromium שהותקן דרך `pkg`. אם מותקן דפדפן במיקום אחר, הגדירו את הנתיב ב־`CHROME_PATH` בתוך `.env`.

להגדרות מותאמות, העתיקו את `.env.example` לקובץ `.env` ועדכנו בו את הערכים. הבוט טוען את ההגדרות גם בצד Node וגם בצד Python.

ההפעלה נשארת פתוחה ומפעילה מחדש את הבוט אוטומטית אחרי שינוי בקבצי הקוד, בלי צורך להריץ שוב. להפעלה חד־פעמית ללא watcher השתמש ב־`./runwhatsapp.sh --once`.

אם צריך להשתמש בגיבוי החיפוש דרך Playwright, במחשב רגיל התקן גם דפדפן Chromium פעם אחת: `./.venv/bin/python -m playwright install chromium`. ב־Termux אין להריץ את פקודת ההורדה הזו; השתמשו ב־Chromium שהותקן עם `pkg` והשאירו את `CHROME_PATH` ריק או הגדירו את הנתיב שלו.

בהפעלה הראשונה סורקים את ה־QR דרך WhatsApp > מכשירים מקושרים. בהפעלות הבאות ה־session נטען אוטומטית.

## פקודות WhatsApp

- `!חיפוש` — חיפוש טיסה.
- `!רשימה` או `הרשימה שלי` — הצגת כל הטיולים והטיסות; כל טיסה נשלחת בהודעה נפרדת.
- `טיול לשוויץ` או `!טיול חדש` — פתיחת טיול והוספת טיסות.
- `הלוך` / `חזור` — בחירת מקטע והזנת יעד או מקור, תאריך, מספר טיסה וחברת תעופה.
- `המשך טיול <קוד>` — חזרה לטיול קיים והוספת מקטעים נוספים; הקוד מופיע ב„הרשימה שלי”.
- `סיום טיול` — סיום הוספת מקטעים; הטיסות שכבר נשמרו ממשיכות להיות במעקב.
- `!פינג` — בדיקת חיבור.
- `!מזהה` — הצגת מזהה הצ׳אט.
- `!עזרה` — עזרה.
- `מדריך שימוש` — הסבר מפורט על החיפוש, שמירת מעקב וההתראות.

במהלך חיפוש אפשר לכתוב `הבא`, `הקודם`, `מעקב` או `ביטול`.

אפשר גם לשלוח חיפוש מלא בהודעה אחת, למשל: `אני טס לציריך בתאריך 30.10.2026 עם חברת ארקיע`. אם נמצאו טיסות בכמה שעות, הבוט יבקש לבחור בוקר, צהריים, ערב או לילה; אם נשארו כמה אפשרויות באותו חלק יום, הוא יציג את השעות ומספרי הטיסה. לאחר מכן יוצגו פרטי הטיסה והבוט ישאל אם זו הטיסה שלך. רק לאחר אישור נוסף הוא ישמור אותה למעקב.

טיסה טבעית שנשמרת נפתחת כטיול חדש, כדי שאפשר יהיה להוסיף אליה חזור אחר כך: השתמשו ב„הרשימה שלי” לקבלת קוד הטיול, ואז כתבו `המשך טיול <קוד>` ו־`חזור`. בחיפוש מדורג עם `!חיפוש` אפשר עדיין לכתוב `מעקב` אחרי בחירת תוצאה.

אם חסרים פרטים, אפשר לכתוב גם ניסוח טבעי כמו `אני טס לציריך מתאריך 18.11 עד 21.11`. הבוט ישאל באיזו שנה רק אם לא צוינה שנה באף אחד מהתאריכים; אם תאריך ההלוך והחזור חוצים שנה, הוא מסיק זאת לפי סדר התאריכים. לאחר הצגת התוצאות כתבו `הלוך` או `חזור` לבחירת מקטע, `הבא` או `הקודם` לשינוי הטיסה באותו מקטע, ו־`מעקב` לשמירת הטיסה המוצגת. אפשר לשמור כל אחד מהמקטעים בנפרד. כשלא נכתב יעד חזרה, תל אביב משמשת כברירת המחדל של הטיסה החוזרת.

אחרי פתיחת טיול, הבוט מבקש כל פרט בנפרד, מחפש בלוח ומאפשר לבחור תוצאה. כתבו `מעקב` כדי לשייך אותה לטיול; לאחר מכן אפשר להוסיף טיסה הלוך או חזור נוספת. לדוגמה: `טיול לשוויץ` → `הלוך` → פרטי הטיסה → `מעקב` → `חזור` → פרטי הטיסה → `מעקב` → `סיום טיול`.

המעקבים נשמרים במסד הנתונים לפי המשתמש והטיול. הבוט מבצע בדיקה ראשונית לאחר החיבור ולאחר מכן סורק בכל שעה עגולה את כל הטיסות השמורות, מכל הטיולים של המשתמשים. עדכון נשלח בנפרד וכולל את שם הטיול; אם שליחת עדכון נכשלת, מצב הטיסה לא מתקדם והבדיקה הבאה תוכל לנסות לשלוח אותו שוב.

## קבצים חשובים

- `whatsapp_bot.js` — חיבור WhatsApp Web וניהול השיחה.
- `flight_parser.js` — פענוח ניסוחי חיפוש טבעיים בעברית.
- `trip_list.js` — סידור הרשימה לפי טיולים והפקת הודעה נפרדת לכל טיסה.
- `flight_time_selection.js` — סיווג שעות ותגובות של בחירת חלק היום.
- `whatsapp_service.py` — bridge בין WhatsApp לליבת הטיסות.
- `flight_core.py` — חיפוש בלוח נתב״ג, התאמת חברות וניהול SQLite.
- `airline-alias-database.json` — שמות וקודי חברות תעופה.
- `runwhatsapp.sh` — launcher והתקנת חבילות Node ו־Python בפעם הראשונה.
- `test/flight_parser.test.js` — בדיקות לפענוח מסלול ותאריכי הלוך־חזור (`npm test`).
- `test/flight_time_selection.test.js` — בדיקות לסיווג בוקר, צהריים, ערב, לילה ושעה חסרה (`npm test`).
- `test/natural_flight_conversation.test.js` — סימולציית שיחה שמוודאת בחירת שעה, אישור ושמירת טיול (`npm test`).
- `test/trip_list.test.js` — בדיקות להצגת טיולים וטיסה נפרדת לכל הודעה (`npm test`).
- `test/test_trip_database.py` — בדיקות הגירת SQLite, שיוך טיסות ובדיקת כל הטיסות שבטיולים (`npm run test:python`, לאחר `./runwhatsapp.sh`).

## אבטחה

אין לשתף את `.wwebjs_auth`, `.env` או את מסד הנתונים. זהו חיבור WhatsApp Web לא רשמי ועלולים להיות ניתוקים או מגבלות מצד WhatsApp. אין להשתמש בו לשליחת הודעות המוניות.
