# WhatsApp Flight Bot

בוט WhatsApp Web למעקב אחר טיסות מנתב״ג. החיבור משתמש ב־QR וב־session מקומי שנשמר בתיקיית `.wwebjs_auth`.

## הפעלה

```bash
./runwhatsapp.sh
```

בהפעלה הראשונה הסקריפט מתקין את חבילות Node, יוצר סביבת Python מקומית ומתקין את התלויות מ־`requirements.txt`. נדרשים Node.js ו־Python 3. אם מגדירים `PYTHON_EXECUTABLE`, הסקריפט ישתמש בו במקום בסביבת ברירת המחדל.

### Termux / Android

```bash
pkg update
pkg install nodejs python chromium
```

הסקריפט מדלג בכוונה על הורדת Chromium של Puppeteer, שאינה נתמכת ב־Termux, ומשתמש ב־Chromium שהותקן דרך `pkg`. אין צורך להתקין Playwright ב־Termux.

להגדרות מותאמות, העתיקו את `.env.example` לקובץ `.env` ועדכנו בו את הערכים. אין למחוק את `.env`, את `.wwebjs_auth` או את מסד הנתונים בעת עדכון הפרויקט.

## שימוש בשיחה

אין צורך בסימן `!` ואין צורך בקודים פנימיים. הבוט שואל לפי שם הטיול ובוחר טיסות לפי הפרטים שהמשתמש שולח.

### חיפוש טיסה

אפשר להתחיל בשיחה טבעית:

```text
אני טס לציריך בתאריך 30.10.2026 עם חברת ארקיע
```

או לכתוב:

```text
הלוך
```

ואז לשלוח את פרטי ההלוך. לאחר בחירת הטיסה הבוט ישאל אם יש גם חזור. אם עונים כן, שולחים את פרטי החזור; בסיום הבוט שואל אם ליצור טיול ולקבל עדכונים. רק לאחר אישור נוצר טיול והטיסות נשמרות בו.

### טיול ידני

```text
טיול לשוויץ
```

הבוט יבקש הלוך או חזור, יחפש את הטיסה ויאפשר להוסיף מקטעים נוספים. אפשר גם לכתוב `טיול חדש` ולקבל בקשה לשם הטיול.

### רשימה והמשך

```text
הרשימה שלי
```

הרשימה מציגה את שמות הטיולים, הטיסות והאם העדכונים פעילים או מושהים.

```text
המשך טיול
```

הבוט יציג את שמות הטיולים וישאל באיזה מהם להוסיף טיסה. אפשר גם לכתוב `המשך טיול שם הטיול`.

### עדכונים

```text
בטל עדכונים
```

הבוט יבקש לבחור טיול לפי שם ויפסיק את העדכונים עבור כל הטיסות שבו, בלי למחוק דבר.

```text
המשך עדכונים
```

מחזיר את העדכונים לטיול שנבחר. כך אפשר להשהות טיול ולחדש אותו מאוחר יותר.

### עריכה ומחיקה

```text
ערוך טיול
ערוך טיסה
מחק טיול
מחק טיסה
```

הבוט יבקש לבחור את הטיול או הטיסה בשיחה. מחיקת טיול או טיסה דורשת אישור נוסף. אפשר לבטל כל פעולה באמצעות:

```text
ביטול
```

### עזרה

```text
עזרה
מדריך שימוש
```

## בדיקות

- `npm test` — בדיקות JavaScript.
- `npm run test:python` — בדיקות Python לאחר התקנת התלויות.

## קבצים חשובים

- `whatsapp_bot.js` — חיבור WhatsApp Web, חיפוש ושיחה.
- `flight_parser.js` — פענוח ניסוחי חיפוש טבעיים בעברית.
- `trip_list.js` — הצגת טיולים וטיסות ללא חשיפת מזהים פנימיים.
- `whatsapp_service.py` — bridge בין WhatsApp למסד הנתונים ולליבת הטיסות.
- `flight_core.py` — חיפוש בלוח נתב״ג, התאמת חברות וניהול SQLite.
- `runwhatsapp.sh` — launcher והתקנת חבילות Node ו־Python.

## אבטחה

אין לשתף את `.wwebjs_auth`, `.env` או את מסד הנתונים. זהו חיבור WhatsApp Web לא רשמי ועלולים להיות ניתוקים או מגבלות מצד WhatsApp. אין להשתמש בו לשליחת הודעות המוניות.
